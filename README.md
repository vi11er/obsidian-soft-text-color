# Obsidian Soft Text Color (Hidden Span)

Лёгкий плагин для **Obsidian**, который:
1. Полностью скрывает теги `<span style="color: ...">` и `</span>` в режиме редактирования (Live Preview / Source), оставляя видимым только сам цветной текст — даже когда курсор стоит на этой строке или внутри слова.
2. Добавляет в контекстное меню правой кнопки мыши пункт **«Цвет текста →»** с палитрой из 7 приглушённых цветов (нежно-фиолетовый, нежно-розовый, зелёный, жёлтый, красный, голубой, синий) и кнопкой **«Сбросить цвет»**.

## Установка через BRAT
1. В Obsidian откройте **Настройки → BRAT → Add Beta plugin**.
2. Вставьте ссылку на этот репозиторий и нажмите **Add plugin**.
